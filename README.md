## 技术说明

- 纯前端、零依赖、离线可用（公式用 HTML 排版，不引 MathJax）
- OLS：正规方程 β=(X'X)⁻¹X'y + 高斯-约当求逆
- p 值：不完全 Beta 函数（Lanczos logGamma + betacf/betai）→ t 双尾 p、F 上尾 p
- VIF：逐变量对其余变量回归，取 1/(1−R²j)
- 验证：页面 JS 引擎输出与 Python（同一份数据）逐位一致 → R²=0.825、调整 R²=0.802、F=36.44
